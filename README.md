One out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The reply

> I'm on vacation. Your email has been delegated to a script that filed it under 'probably fine'.

95 characters. The agent is on vacation, and your email has been handed down to a script that files it under "probably fine".

## How it works

`main.py` (stdlib only) writes the reply to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is 1–160 characters and not only whitespace, and verifies the write by reading it back.

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
